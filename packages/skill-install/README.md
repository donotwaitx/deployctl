# deployctl-skill

Zero-config installer for the official **deployctl Agent Skill**.

Equips **Claude Code**, **Cursor**, **GitHub Copilot**, and **Google Antigravity** with safe differential FTP/SFTP deployment workflows and credential protection.

---

## ⚡ Quick Start

Install globally for all agents:
```bash
npx deployctl-skill
```

Install specifically for Claude Code:
```bash
npx deployctl-skill --agent claude
```

Install locally inside active project:
```bash
npx deployctl-skill --project
```
